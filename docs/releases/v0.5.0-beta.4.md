# gpuicn v0.5.0-beta.4

This release brings the full GPUI Kit 0.6.2–0.6.4 component update into
gpuicn. It adds styled Carousel, Empty and Input Group components, and exposes
the existing styled Textarea as its own catalog and install target. Carousel
keeps GPUI Kit's native pointer, trackpad and keyboard engine while gpuicn
applies the Nova surface and keeps its internal hover, pressed and focus tokens
in sync with `UiTheme`.

The runtime moves to GPUI Kit 0.6.4, GPUI 0.3.5 and gpui-icons 0.4.1. Keep
these versions together: older gpui-icons releases pin GPUI 0.3.4 and conflict
with the new platform dependency. Full component initialization now registers
Carousel actions and the operating system reduced-motion setting.

Input and Textarea gain native paste interception for image and file payloads.
Select clears its filter when it closes, so reopening shows every option.
Dialog and Alert Dialog controls now route their actions through the dialog
that owns them, including when another control holds focus. Textarea now
composes directly with `Field` for labels and validation.

This release also includes the source-adoption fixes merged after beta.3:
consistent validation for mixed forms, saved-value selector initialization,
and install commands that include each example's required components. The
workspace download page now groups macOS and Linux, with an architecture
picker for Linux. Both site domains remain in the deployment configuration.

Reinstall copied components with an explicit overwrite after saving your local
edits. Existing installed Rust source does not update itself. Use the beta.4
CLI and tagged registry together; the installation guide contains the exact pins.

Linux downloads remain experimental. ARM64 runtime, broad Linux desktop
compatibility, full screen-reader workflows and performance budgets remain
unqualified. Upstream mobile support does not qualify gpuicn on iOS or Android.

The dependency-only baseline passed native tests, Clippy, both registry-install
paths, the WASM build and web checks in
[CI run 35568636838](https://github.com/devaryakjha/gpuicn/actions/runs/35568636838).
That run predates the new component source and is not final release evidence.
The expanded registry, native showcase and WASM catalog must pass from the
release commit before beta.4 is published.
