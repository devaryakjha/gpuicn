# gpuicn v0.5.0-beta.1

This beta adds gpuicn Workspace, a native example app with saved projects,
tasks, notes and an on-device message log. The component gallery opens from
the app, and the website includes the macOS download.

- Add Sidebar, Resizable and Virtual List, bringing the catalog to 40 component families.
- Add a Rust source-installation CLI with theme support and overwrite protection. The CLI builds from source; it is not published to crates.io.
- Share native text editing across Input, Field, NumberField and Toolbar, including undo/redo, word editing, IME composition and accessible editor names.
- Fix modal focus, required-form submission, disabled controls and keyboard navigation.
- Preserve task drafts, guard unsaved edits, save workspace data atomically, and make the introduction dismissible.

The macOS download targets Apple silicon. Unzip it, move **gpuicn Workspace**
to Applications, and open it. Local chat stays on the Mac; it does not connect
to other people or generate replies.

Registry users should pin this release, reinstall the components they need,
and review the copied-source diff. Initialize installed components with
`ui::theme::init(cx)` so native keyboard actions are available. Existing copied
source does not update automatically.

Validation includes 44 workspace tests, fresh registry installation, native
task and editing journeys, and browser previews. See the
[audit record](../validation/showcase.md) for the checks and their limits.

APIs and styling may change during beta. The download does not include an
Intel build, and this release does not claim full accessibility or platform parity.
