# gpuicn v0.5.0

gpuicn drops the beta suffix with this release. It is still experimental:
APIs and styling can change between minor versions, and `gpuicn diff` shows
what an update changes in your copy.

The runtime moves to GPUI Kit 0.8.1 and its pinned `gpui-pre` 0.3.10. No
component API changes. Keep these pins together:

```toml
gpui_platform = { package = "gpui-pre-platform", version = "=0.3.10", features = ["font-kit"] }
gpui-icons = "=0.5.0"
gpui-kit = { version = "=0.8.1", default-features = false, features = ["component"] }
```

GPUI Kit 0.8 makes some of its own changes, such as scroll bounce by default on
macOS and the `ScrollWheelEvent` rename to `ScrollEvent`. See its
[release notes](https://github.com/longbridge/gpui-kit/releases) if your app
uses GPUI Kit directly.

gpui-icons 0.5.0 bundles Lucide 1.63.0, with 1,924 icons. Ten icons Lucide
renamed keep their old names as aliases and constants, so
`LucideIcon::Music` still works and points at `EighthNotes`.

Installed source never updates itself. After upgrading the CLI, run
`gpuicn diff` to review the changes, then `gpuicn add <component> --overwrite`.
