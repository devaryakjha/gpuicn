# gpuicn v0.5.0-beta.5

This release is about setup and day-to-day use.

`gpuicn new my-app` creates an app that runs with `cargo run`, and
`gpuicn init` now does the whole setup in an existing app: pinned Cargo
dependencies, checksum-verified Geist fonts, the theme, Button and a starter
window. `gpuicn status`, `diff` and `remove` manage the installed source, and
`cargo gpuicn` works as an alias.

Crate mode is new. `gpuicn new my-app --crate` depends on the `gpuicn` crate
instead of copying source, and `gpuicn eject <component>` copies one component
into the app when you want to change it. Call sites read `ui::<component>` in
both modes, so ejecting never changes them.

Several component APIs changed shape so that every component works the same
way: required inputs go to `new`, and the rest are builder methods. Toast takes
a `Notice`, Resizable and SidebarLayout use builders, `dialog_trigger` and
`dialog_action` no longer take `cx`, and `fieldset_root` is now `fieldset`.
The [changelog](../../CHANGELOG.md) has a before/after table.

`UiTheme::from_shadcn_css` imports shadcn and tweakcn themes. The minimum Rust
is now 1.97, with gpui-icons 0.4.2.

Installed source never updates itself. After upgrading the CLI, run
`gpuicn diff` to review the changes, then `gpuicn add <component> --overwrite`.
