# gpuicn v0.9.1

Seven additions Matty asked for while building its chat client. Every change
is additive: existing code compiles and draws as before, and installed source
from v0.9.0 changes only in the files below (`gpuicn diff` lists them). The
runtime pins are unchanged: GPUI Kit 0.9.0 on `gpui-pre` 0.3.11 and gpui-icons
0.6.0.

## Added

- **Message**: `timestamp_tooltip` shows the full date and time when the
  reader hovers the time, on header, continuation and compact rows (#94).
  `on_gutter_click` makes the avatar column a click target for selecting the
  row, while clicks on the body stay free for text selection and links (#98).
- **Toast**: `Notice::action(label, handler)` and `Notice::cancel(label)` add
  buttons to a notification. Pressing either dismisses it; the action runs its
  handler first. Tab reaches them before the close button, and hovering the
  stack pauses the timeout as before (#95).
- **MessageList**: `on_jump` hands the "Jump to latest" pill to the
  application, which can load the newest page after a jump into the past
  instead of scrolling to the loaded end. `show_jump(true)` keeps the pill
  visible at the loaded end of such a window (#97).
- **Attachment**: `dimensions(width, height)` sizes an image thumbnail from the
  file's metadata, keeping its aspect ratio inside `max_size` (360 × 240 by
  default), and holds that box with a muted fill while the image loads, so the
  transcript does not jump (#99).
- **Sidebar**: `roving_focus(true)` makes the navigation rows one tab stop.
  Tab lands on the focused or selected row and the next Tab leaves; Up and
  Down move between rows (wrapping, skipping disabled ones), Home and End jump
  to the ends, and the focused row scrolls into view (#100).
- **Composer**: `ComposerState::set_max_rows` and `max_rows` change the growth
  cap without rebuilding the state, and `Composer::max_height(px)` caps the
  text box in pixels, for example at 40% of the window, following resizes and
  keeping the draft (#101).
- **ScrollArea**: `track_scroll(&ScrollHandle)` shares the scroll position
  with the caller.

## Upgrading

```sh
cargo install gpuicn-cli --version 0.9.1 --locked
gpuicn update --to 0.9.1
```

Crate users: `cargo update -p gpuicn`.
