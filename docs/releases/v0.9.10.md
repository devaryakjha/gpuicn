# gpuicn v0.9.10

A transcript performance fix found while profiling Matty's scrolling
(karyalabs/matty#674). The runtime pins are unchanged: GPUI Kit 0.9.0 on
`gpui-pre` 0.3.11 and gpui-icons 0.6.0.

## Changed

- `Message` lays out its hover action bar only for the hovered or selected
  row. Before, every row laid out, hit-tested and painted a hidden bar on
  every frame. The bar stays while the pointer is on it, even where it floats
  above the row.

## Added

- `Message::actions_with`, which builds the bar only when it shows, so a long
  transcript does not build a toolbar per row each frame. `Message::actions`
  still works and takes an already-built bar.
