# gpuicn v0.5.0-beta.2

This beta moves all 40 component families and gpuicn Workspace directly to
GPUI Kit 0.6.1, updates Lucide icons, and fixes component layout, keyboard and
motion issues found during native and browser checks.

- Replace the previous GPUI base and compatibility package with GPUI Kit. Input,
  menu, selector, form, dialog and drawer APIs now use Kit state and handles.
- Add responsive drawer layouts, fixed headers and footers, scrollable bodies,
  grip dragging and reversible transitions that respect reduced motion.
- Fix Select commits and its WASM font crash; improve disclosure, progress and
  toast motion; restore tooltip focus and Escape handling; keep long dialogs
  scrollable; and guard disabled accordion clicks and resize cancellation.
- Give sidebar workspace and account menu triggers room for two-line labels
  and padding, while keeping icons within the collapsed rail.
- Preserve native task and message entry, menu focus, form submission and
  keyboard activation in the browser previews.

This release changes copied-source APIs. Reinstall the components you use and
review the source diff, dependency setup and updated Usage examples. Initialize
installed components with `ui::theme::init(cx)`. Existing copied source does not
update automatically. The source-installation CLI remains unpublished to crates.io.

The macOS download targets Apple silicon. Unzip it, move **gpuicn Workspace**
to Applications, and open it. Workspace data and messages stay on the Mac.

Validation includes 45 workspace tests, an independent registry installation,
native task and message entry, and browser interaction checks. See the
[migration qualification](../validation/gpui-kit-migration.md) for evidence and
limits. Windows/Linux runtime, OS IME, full screen-reader workflows and
performance budgets remain unqualified. APIs and styling may change during beta.
