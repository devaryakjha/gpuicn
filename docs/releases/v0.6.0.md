# gpuicn v0.6.0

This release adds the components a chat app needs, plus a set of small
primitives. Runtime pins are unchanged from v0.5.0: GPUI Kit 0.8.1 on
`gpui-pre` 0.3.10, and gpui-icons 0.5.0.

## New components

- **Command**: a filterable, grouped command list with icons, shortcuts,
  keywords and disabled items. Arrow keys move, Enter confirms, and Escape
  clears the query before it cancels. `command_dialog_popup` makes a ⌘K
  switcher.
- **Message**: a chat row with avatar, author and time, continuation rows,
  mention and selected highlights, pending and failed states, reaction chips
  and a hover action bar. Day and new-messages dividers are included.
- **Message List**: a variable-height, virtualized transcript built on GPUI
  Kit's `MessageScroller`. It keeps its place when older history loads, and
  its jump pill counts unseen messages.
- **Attachment**: file cards and image thumbnails with upload progress,
  failed, retry and remove states, and `attachment_group` for a scrolling row.
- **Title Bar**: a custom title bar with dragging, double-click to zoom and
  window controls on Windows and client-decorated Linux. It leaves room for
  the traffic lights on macOS.
- **Markdown**: GPUI Kit's Markdown view with gpuicn styling for code blocks,
  tables, quotes and inline code. The `EntityLinks` plugin turns links such
  as `[@arya](mention:arya)` into clickable chips.
- **Kbd**, **Badge**, **Tag**, **Spinner** and **Skeleton**. Kbd shows ⌘K on
  macOS and Ctrl+K elsewhere, including for `secondary-` bindings. Spinner and
  Skeleton hold still under reduced motion.

Command, Attachment, Title Bar and the Message List jump pill draw Lucide
icons through gpui-icons. GPUI Kit's own versions load icons from
`icons/*.svg`, which a gpuicn app does not serve.

## Code highlighting

Markdown code blocks are highlighted when the `syntect` feature is on:

```toml
gpuicn = { version = "0.6", features = ["syntect"] }
```

Copied-source apps can enable `gpui-kit`'s `syntect` feature directly.

## Upgrading

The theme now passes link, selection, table and code-highlight colors to GPUI
Kit. In crate mode this comes with the update. Installed source never updates
itself, so copied-source apps should run `gpuicn diff`, then
`gpuicn add theme --overwrite`, before adding the new components.
