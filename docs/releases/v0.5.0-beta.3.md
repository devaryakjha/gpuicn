# gpuicn v0.5.0-beta.3

Focus now changes the control's border color without adding a halo or changing
its background. Platform notes render Markdown correctly across all 40 component
pages, including inline code, links, lists and the Sidebar table.

- Remove focus shadows and custom ring drawing from the components. Preserve
  keyboard focus, validation colors, and sidebar trigger spacing.
- Render Platform notes during the website build using Bun's Markdown support.
  Resolve relative documentation links and check every component's output in CI.

The `UiTheme::focus_ring()` and `UiTheme::destructive_focus_ring()` helpers were
removed. Custom controls should set their focus border color directly. Reinstall
copied components to receive the changes; existing source does not update itself.

Validation: 44 workspace tests, Clippy, an independent source installation,
optimized native and WASM builds, web build, TypeScript and lint. Browser checks
cover all 40 Platform notes sections and focus on normal, invalid, numeric and
OTP inputs, buttons, tabs and sidebar dropdowns in the updated preview.

The macOS download targets Apple silicon. Unzip it, move **gpuicn Workspace**
to Applications, and open it. Workspace data and messages stay on the Mac.
This remains a beta; Windows/Linux runtime, full screen-reader workflows and
performance budgets remain unqualified.
