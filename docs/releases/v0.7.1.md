# gpuicn v0.7.1

A maintenance release with no changes to the components, the crate API or the
CLI. Installed source from v0.7.0 is identical; `gpuicn diff` shows nothing.

## Changed

- The website's WASM preview is built with `wasm-opt -Oz`, which shrinks it
  from 25.8 MiB to 13.7 MiB. At 25.8 MiB it was over Cloudflare's 25 MiB asset
  limit, so the v0.7.0 site could not deploy. This release puts the 0.7.0
  components on ui.imajha.com.
- Releases now run entirely in CI. Merging a version bump to `main` tags it,
  publishes `gpuicn` and `gpuicn-cli`, builds the signed and notarized macOS
  app and the Linux archives, publishes the GitHub release and deploys the
  website. See [CONTRIBUTING](../../CONTRIBUTING.md#releases).
