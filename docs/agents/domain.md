# Domain docs

This repository uses a single domain context.

Before exploring, read:

- `CONTEXT.md` at the repository root, when present.
- Relevant decisions under `docs/adr/`, when present.

Proceed silently when either path does not exist. Domain-modeling skills create them only when real terms or decisions need recording.

Use terms defined in `CONTEXT.md`. Flag any proposed change that conflicts with an existing ADR.
