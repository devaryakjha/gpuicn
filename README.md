# imajha/ui

Open-code components for [GPUI](https://www.gpui.rs/), built on
[Base GPUI](https://github.com/LukeTandjung/base-gpui).

The project will follow the shadcn/ui model: add component source to your app,
then own and adapt it.

> This project is at an early stage. No components have shipped yet.

Website: [ui.imajha.com](https://ui.imajha.com)
